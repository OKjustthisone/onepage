# OnePage - 智能防重复标签页浏览器扩展

**OnePage** 是一款轻量、现代且高效的浏览器扩展（基于 Chrome Extensions Manifest V3 标准构建），专为解决浏览器标签页无限堆积、重复打开相同网页的问题而设计。

---

## ✨ 核心特性

### 1. 智能防重复检测
- 当你在浏览器中打开新网页（通过地址栏输入、点击外部链接、其他应用唤起等）时，扩展会自动比对当前已打开的所有标签页。
- **全新页面**：若之前从未打开过，正常加载，毫无干扰。
- **重复页面**：若相同 URL 已经存在，根据你选择的模式自动执行去重。

### 2. 双去重模式灵活切换
在扩展弹窗（Popup）或设置页中，可随时一键切换以下两种策略：
1. **模式一：自动跳转到已有页面（推荐）**
   - 自动切回并激活之前已打开的旧页面所在窗口与标签，同时**自动关闭新开的重复标签**。
   - 显著节省系统内存与 CPU 消耗，告别标签栏混乱。
2. **模式二：保留新开页面**
   - 继续打开并保留新页面，同时在**后台静默关闭之前打开的重复旧页面**。
   - 适合喜欢每次刷新查看最新内容、但不希望后台残留无用旧标签的用户。

### 3. 允许随时打开重复页面（免拦截机制）
当你需要临时对照两份相同页面、或者在多个窗口中同时查看同一网页时：
- **扩展图标一键打开**：点击浏览器右上角的扩展图标，点击醒目的 **【允许打开重复页面】** 按钮，立即克隆当前网页，本次打开将直接跳过去重机制。
- **全局快捷键**：按下 `Alt + Shift + D`（Mac 上为 `Option + Shift + D`）直接免去重克隆。
- **右键上下文菜单**：在网页空白处或扩展图标上单击右键，选择 *“OnePage: 允许打开当前页面的重复标签”*。

### 4. 强大的 URL 匹配规则与白名单
- **域名白名单**：在弹窗中一键勾选“允许重复”，或在设置页添加白名单域名（例如在线会议 `meet.google.com`、多人协同文档、开发调试 `localhost` 等）。
- **智能过滤推广参数**：自动忽略 `utm_*`、`spm`、`ref`、`fbclid` 等营销追踪参数，避免同一个网页因为携带了不同追踪后缀而被误判为不同页面。
- **忽略末尾斜杠与锚点**：自动平滑标准化 `https://example.com/` 与 `https://example.com`，以及忽略内部页面定位锚点 `#section`。
- **保护固定标签（Pinned Tabs）**：在模式二下可开启保护，防止固定的常用标签页被意外在后台关闭。
- **跨窗口检测**：支持跨多个浏览器窗口联合检测重复。

## 🚀 安装步骤（Chrome / Edge / 任意 Chromium 浏览器）

1. 打开浏览器并进入扩展程序管理界面：
   - **Chrome**: 在地址栏输入 `chrome://extensions/` 并按回车
   - **Edge**: 在地址栏输入 `edge://extensions/` 并按回车
2. 在页面右上角（或左下角）找到并开启 **“开发者模式” (Developer mode)**。
3. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)** 按钮。
4. 在弹出的文件选择器中，选择本项目的目录：
   ```
   /Users/nutcracker/Myapp/onepage
   ```
5. 加载完成后，在浏览器右上角拼图图标中将 **OnePage** 固定到工具栏即可正常使用！

## 💡 使用小贴士

1. **临时多开对比**：需要同屏对比两个相同网页时，不要直接粘贴 URL，而是直接按快捷键 `Alt+Shift+D` 或在插件面板中点击“允许打开重复页面”。
2. **开发环境调试**：若你在开发本地项目（如 `localhost:3000` 或 `127.0.0.1`），可以直接在插件弹窗中开启“允许重复”，避免影响多开调试。
